## 判定口径

- **已支持**：找到接入代码、公共能力或用户入口，不因为没有复刻官方 TUI 就说缺失。
- **部分支持**：CLI/SDK 可执行或模型可触发，但缺少管理入口、事件状态、恢复或配置闭环。
- **未提供专门入口**：官方存在，所检查代码未找到对应映射；不等于底层模型绝对不能调用。
- **待验证**：协议或版本差异已经存在，但没有真实对应版本会话回归，不能写成已复现故障。
- **不直接适用**：官方云服务、TUI 私有界面、已取消功能，不应机械移植到 Paseo。

P0 指优先确认可能阻断启动、工具注入或完成状态的协议问题，不表示已经证明发生数据损坏；P1 为高收益功能补齐；P2 为辅助管理或展示。所有建议都是待用户选择的独立工作，不是待自动导入的补丁清单。

代码依据中的路径从仓库根目录解析，优先定位函数名和 RPC 方法，避免把行号变化误当成证据失效。各报告的官方链接与本地依据共同构成结论：官方文档证明能力，Paseo 代码证明当前接入范围；不能互相替代。
