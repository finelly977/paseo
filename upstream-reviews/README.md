# 上游情报评估

本目录记录对 [getpaseo/paseo](https://github.com/getpaseo/paseo) 后续发布版本的只读评估。本项目不再跟随上游代码，评估目的只有两个：

1. 发现当前二开尚未提供、值得独立实现的新功能。
2. 发现上游修复且经检查确认二开也存在的共性缺陷。

## 记录方式

- 默认只评估最新已发布标签，包括正式版和预发布版；只有用户明确要求时才查看未发布分支或 PR。
- 一个已评估发布标签对应 `tags/vX.Y.Z.md`；首次需要时再创建 `tags/` 目录和记录文件。
- 每项新功能写清用户收益、二开当前是否已有等价能力，以及是否值得独立实现。
- 每项缺陷先检查二开代码、测试或复现路径，再标记为“二开同样存在”或“仅上游存在”。未经验证不得写成二开缺陷。
- 纯重构、依赖升级、品牌内容和上游专属界面改动可以汇总排除，不逐提交维护合并状态。
- 记录中不得出现“待合并”“可直接挑选”等接入建议；需要落地的功能或修复必须以二开现有架构独立实现。

历史选择性合并记录保留在 [upstream-merges/](../upstream-merges/)，该目录已经冻结。
