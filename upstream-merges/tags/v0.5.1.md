## 建议合并

### `e268d1a89` 手机端输入框在切换会话后不再自动变高

**做什么**
iOS / Android 的多行输入框,高度由 JavaScript 计算的那套逻辑和原生控件自己的布局互相打架,在草稿和智能体之间切换归属时就不再随内容增高。合并后让原生输入框自己负责尺寸和滚动,网页端保留原有的 DOM 测量方式。

**对二开的影响**
只动原生端输入框,二开未改这条路径,可直接应用。

**建议:合并,且必须和 [v0.5.0.md](v0.5.0.md) 里的 `35cde075a` 一起。** 两者是同一个问题的两半:`35cde075a` 处理原生首帧回调缺失和删除后高度不回缩,这一条处理归属切换时的竞争。只合一条会留下半截状态。

## 冲突已解决

- `e268d1a89` 与 `v0.5.0` 的 `35cde075a` 成组适配：网页端保留 DOM 镜像测量；原生端不再让 JavaScript 内容高度和原生固有布局竞争，始终由输入框管理滚动；输入框根布局变化统一通知父级。没有引入上游后续输入组件、键盘作用域和只读模式重构。
