# 上游合并历史（已冻结）

本目录保存二开仓库过去对 [getpaseo/paseo](https://github.com/getpaseo/paseo) 已发布版本进行选择性合并的历史记录。

自 2026-09-17 起，本项目不再跟随、合并或挑选原作者代码。本目录因此永久冻结：

- 不再新增上游合并任务、待处理提交或合并水位线。
- 现有标签文件只用于解释历史代码来源和过去的冲突处理，不代表仍需继续完成其中的延期项。
- 不得根据旧记录执行 `merge`、`rebase`、`cherry-pick`、补丁套用或整文件覆盖。
- 今后对上游发布版本的只读评估记录放在 [upstream-reviews/](../upstream-reviews/)。
